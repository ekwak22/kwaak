# Kwaak YoungHoon — A Life of Vision

Open index.html. No installation, internet connection or build step is required.

## Four bilingual pages
- index.html: three clear visual entrances.
- person.html: three stories about purpose, learning and service.
- nation.html: six stories about public spaces, infrastructure, international events and national planning; additional illustrated planning concepts.
- world.html: four stories about Olympeace, the Silk Road Mayors Forum, regional cooperation and peace-city visions; interactive forum host-city explorer.

English / 한국어 switches all page text, captions and controls. The language choice is remembered when browser storage is available and is also carried in page links. Full story text is present directly in the HTML. Search works in both languages. Click a photograph or drawing to enlarge it; press Escape to close.

## Editorial approach
The website is a selective tribute, not a list of every assignment. Thirteen core stories prioritize documented roles, enduring public places, civic service and international cooperation. Original photographs and drawings are extracted from the supplied materials. Plain-text source notes retain provenance; visitors do not need to open PDFs or presentations. Proposals are distinguished from completed works. The original source documents are unchanged and are not included in this web package.

## Files and publishing
Keep the four HTML pages, app.js, data.js, styles.css and website/assets together. The ZIP contains only these required website files, this README and .nojekyll. It excludes source PDFs, presentations and working files. Upload the extracted contents to a GitHub Pages repository, with index.html at the root.

## Editing
Page text and captions are paired in data-en / data-ko attributes. Searchable story data is in data.js. Keep those two representations aligned when editing a story. Shared interface text and city names are in app.js; appearance is in styles.css. No source files need to be uploaded for the website to work.
